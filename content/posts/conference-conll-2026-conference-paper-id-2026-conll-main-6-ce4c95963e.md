## 📌 核心摘要

**问题与瓶颈：** 人类与大语言模型都会在语言加工中形成预测，但二者在有视觉支撑的口语中是否同样整合句法结构与韵律线索仍不清楚。现有比较多停留在离线正确率、困惑度、惊奇值或神经对齐，缺少在同一视听场景下同时回答预测什么与预测何时出现的手段。本文任务输入为普通话与格句前子句加连接词而不是，交叉双宾与介词宾语及中性、主题重音、受事重音，视觉输入为提及主题、提及受事、替代主题、替代受事四图，输出为对后续指称的选择与注视分配。根本困难在于形式敏感易被误读为机制相同，而模型跨模态注意力与人类注视并非直接等价，若只看离线输出会掩盖部署时机的差异。

**核心思路与方法架构：** 与最接近的单任务离线人类模型比较不同，本文实质增量是双范式匹配设计，用填空结合视觉世界范式测离线输出，再用标准视觉世界范式测在线时间进程，并在同一套 36 个项目与 2 × 3 拉丁方条件下比较普通话者与冻结的 Qwen2.5-Omni-7B。沿单条样本看，44.1 kHz 录音的前子句经 700 ms 句间静音与 600 ms 而不是连同 1008 × 756 显示输入，模型侧以 25 Hz 音频词元即 40 ms 步长与 27 × 36 图像块编码，抽取音频查询到图像键的自注意力子矩阵，在层内平均多头后映射到四个象限加 REST 并归一化为类兴趣区比例，与人类 50 ms 注视比例同样对齐到目标词起点并计算替代主题对替代受事的对数比率。模型不更新权重，离线以 20 个固定种子生成作试次进入混合模型，在线以层为分组因素建模时间曲线，直接检验结构效应是否在连接词前出现。

**关键实验与核心代价：** 实验 1 离线填空结合视觉世界范式中，人类 4,246 个反应纳入 4,015 个，纳入率为 94.6%，Qwen2.5-Omni-7B 4,320 个生成纳入 2,881 个，纳入率为 66.7%，合并二项混合模型显示模型结构加权更强且韵律整合存在条件特异偏离。实验 2 在线视觉世界范式以替代主题对替代受事分配的对数比率为因变量，在暂停窗 -1300 ms 至 -600 ms 的线性混合效应模型结构主效应 β 指标上，人类为 -0.81 而模型为 -0.03，人类值低于模型值，人类显著而模型不显著。在连接词窗 -600 ms 至 0 ms 的同一 β 指标上，人类为 -1.14 而模型为 -0.17，人类值低于模型值，广义加性混合模型中性条件显著区间人类为 -854 ms 至 0 ms 而模型为 -194 ms 至 0 ms，DO 内受事重音效应人类自 -643 ms 起而模型自 -220 ms 起，诊断模式相似但时间滞后。本研究不涉及语音合成听测故无 MOS 比较，在线结论依赖音频到图像注意力代理而未经因果干预验证，主导代价是模型排除远多于人类排除，输出对齐仅在完全落入替代空间的子集内成立。

**适用边界与深读导览：** 结论成立前提是实验室录制的北京男性声音、规范化时长刺激、剪贴画四图显示与面向模型图像分块的适配提示，结论未覆盖其他多模态模型、模型规模、语言、构式、自然对话噪声与部署端侧条件。深读可查第 3 节双实验设计与注意力抽取流程、附录 A 刺激筛选与录音规范化、附录 B 人类与模型流程及编码排除、附录 C 表 2 至表 9 的混合模型设定与时间窗结果，以核对结构加权与滞后效应的条件边界。

## 🧭 深度解读

### 预测什么与何时预测为何需要分开检验

人类在言语理解中会边听边预测，结合句法结构、韵律重音与视觉场景对后续指称提前形成期待。大型语言模型依靠下一词元预测同样表现出对形式规律的敏感，内部表征还能部分预测神经响应。两者都谈预测，但预测是否发生在同一层面仍需区分。多模态大模型同时处理语音与图像，使研究者可以在共享的视觉约束下比较预测内容与预测时机，为检验认知合理性提供新的对照条件。

#### 输出层面与过程层面的分工

本文沿用马尔的层次区分，把比较拆成两个问题。输出层面问预测了什么，即在给定前文后选择哪一个替代指称。过程层面问何时与如何部署线索，即结构与重音效应在语音展开的哪一段进入注意。形式层面只要求对线索敏感，功能层面还要求在视觉情境中适时调用线索。共享部署预测认为输出相似时时间轮廓也相似，部署分离预测则认为输出相似仍可伴随不同的时间轨迹。前者要求人类注视与模型跨模态注意在可比窗口出现结构与重音效应，后者允许效应出现在语音输入的不同部位或不同时刻。

模型侧过程指标是对共享自注意序列的操作定义。 Qwen2.5-Omni-7B 把文本、音频与图像词元拼入同一序列，没有独立跨模态模块，所谓跨模态注意即音频查询词元对图像键词元的权重。分析取 28 层各自的音频到图像子矩阵，在层内对头平均，再把图像词元映射到四图区域并与剩余区域一起归一化，得到与注视比例可比的区域比例。音频按 25 Hz 换算为 40 ms 步长，与人类 50 ms 分箱对齐，输入在目标名词前截断，层别时间曲线保留并以层为分组因子建模，可视化再做层间平均。

#### 结构焦点与重音作用的搭配

实验载体是普通话双宾与介词与格的对比。双宾结构把接受者放在主题之前，介词结构把主题放在接受者之前，句末默认承载信息焦点。重音设置三水平：中性、主题重音落在被提及的主题、接受者重音落在被提及的接受者。理论上存在两种组合方式：线索汇聚指重音与默认焦点指向同一集合时效应更强，线索诊断性指重音落在缺乏默认焦点的成分上作用更明显。持续焦点假设则认为句末默认焦点即使在显性重音出现后仍继续起作用，结构信息单独不足以解释重音效应。

为此作者提出两个研究问题。第一，人类与 Qwen2.5-Omni-7B 如何整合句法结构与韵律重音来预测视觉场景中的后续指称。第二，当两者输出模式相似时，是否伴随相似的时间部署轮廓。实验 1 用视觉世界中的完形任务测量离线输出，刺激在对比连接词而不是之后截断，被试在四图显示下选择下一提及并给出文字续写。实验 2 用标准视觉世界范式比较人类眼动与模型音频到图像跨模态注意，追踪同一预测窗口内的在线动态，预测窗口从首句偏移延伸至目标词起点，中间以连接词起点划分为早期与晚期两段。

#### 材料匹配与预测窗口的界定

材料与任务在两系统间尽量匹配。36 个项目按 2 × 3 设计分布到 6 个拉丁方名单，每名人类被试只见一名单，每项目在名单内只出现一种条件。每个显示含四图，分别对应被提及主题、被提及接受者、替代主题与替代接受者，角色标签仅为说明，被试不可见。实验 1 在对比连接词而不是之后截断前文，被试边看图边听前文再点选预测并给出续写。实验 2 播放完整句并记录预测窗口，窗口从首句偏移 -1300 ms 延至目标词起点 0 ms ，再以连接词起点 -600 ms 划出早期与晚期两段，因变量为替代主题与替代接受者分配比的对数比值。

### 双实验匹配设计与视听材料如何对应人眼与模型注意

全部材料围绕 2 种结构乘 3 种重音的析因设计组织，共 36 个实验项目，取自 50 个候选中的 22 个改写与 28 个翻译项目，经过音节匹配、实体唯一、可图像化与视觉可区分筛选。项目按拉丁方分配到 6 个表列，每名被试只见每个项目的一种条件，跨表列覆盖全部条件。另有 72 个填充句使用 7 种连接词，平衡人物与非人物目标及重音有无，避免被试对而不是形成策略。录音前经过 159 人完形、128 人自然度与 45 人命名一致性 3 轮规范，终选项目平均自然度为 3.22 。

### 从声波到区域比例的跨模态注意力操作路径

以一次试次为例，流程按顺序推进。第一步呈现 500 ms 注视点与 2,000 ms 四图预览，四图分别对应被提及主题、被提及接受者、替代主题与替代接受者，位置在表列间轮换。第二步播放前文音频，录制采样率为 44.1 kHz 单声道，句间静音统一为 700 ms ，连接词而不是时长统一为 600 ms ，并保留原始基频轮廓。第三步模型处理器把语音转为每 40 ms 一个的音频词元，即 25 Hz ，图像经视觉变换器切为 27 × 36 切片网格。第四步文本、音频与图像词元拼成同一序列送入 28 层变换器，层内多头自注意同时跨越模态。原文未披露隐藏维度与头数，无法列出每步完整张量形状。

#### 跨模态注意的操作步骤

在线指标的操作定义分 5 个步骤。第一步用特殊词元定出音频与图像边界。第二步取出每层注意力矩阵中音频查询对图像键的子矩阵。第三步在层内对头取平均，保留 28 层各自的时间序列，层间变异在统计中作为分组因子处理。第四步按像素坐标把切片映射到 4 个象限，左上 [84, 28, 392, 336] 等 4 组坐标均为 28 像素倍数，其余切片归入剩余区域。第五步在区域内平均并在四象限加剩余区域上归一化，得到与注视比例可比的区域比例。该指标为操作性分配度量，不直接等同于人类注视。

#### 时间窗口与统计建模的衔接

时间统一对齐到目标词起点 0 ms ，预测窗口为首句偏移 -1,300 ms 到目标起点，细分为停顿窗口 -1,300 ms 到 -600 ms 与连接词窗口 -600 ms 到 0 ms 。前者只含结构与重音上下文，后者还出现显性对比连接词。人类按 50 ms 分箱计算注视比例，模型按 40 ms 计算注意比例，因变量均为替代主题与替代接受者比例之比取对数，加 0.001 避免零值。实验 1 用广义线性混合效应模型，结构和编码为双宾 -0.5 与介词 0.5 ，重音以中性为参照。实验 2 窗口分析用线性混合效应模型，时间曲线用广义可加混合模型并做一阶自回归校正，显著区间以逐点置信区间不含零为准，不解读为精确认知起点。

#### 采样重复与分组因素的说明

本研究无模型训练阶段，全部模型侧为冻结推理。解码采用采样模式，温度为 1.0 ，核采样阈值为 0.9 ，最大新词元为 64 ，其余参数沿用默认配置。每个项目在每个表列重复 20 次独立生成，共 4,320 个生成，使用固定 20 个随机种子且每次使用全新对话上下文，单次生成计为一次试次进入模型。人类实验 1 有 118 名被试，实验 2 有 58 名被试，眼动以 1,000 Hz 记录并按 50 ms 分箱。统计上以被试或轮次与项目为随机分组，模型层作为分组因子仅用于建模层间变异，不视为人类被试的认知对应物。

### 离线完形选择显示部分一致但结构权重明显不同

实验 1 比较离线输出，公平性前提是材料、表列与编码规则一致。人类 118 名大学生在线完成，每人 36 个实验与 72 个填充试次。模型对每表列每个项目生成 20 次，共 4,320 次。编码只看文字续写指向的实体，归为替代主题记 1 或替代接受者记 0 ，点击或象限冲突时以文字为准。凡指向画面外实体、已提及实体或模糊与动作描述均不进入二值分析，轮次变异在模型中单独建模。

### 在线时间进程显示人类提前而模型滞后的部署分离

实验 2 进入预测窗口 -1,300 ms 到 0 ms ，因变量为同一对数比。窗口分析在停顿与连接词两段分别拟合线性混合效应模型，曲线分析在全窗口拟合广义可加混合模型，以逐点 95% 置信区间不含零为可靠差异区间，不解释为认知起点。人类以被试为分组，模型以 28 层为分组，层聚合仅用于可视化，推断保留分层时间序列。

#### 人类注视先出现结构效应

人类停顿窗口结构效应为 -0.81 ，t = -2.82 ，p = 0.005 ，重音尚无可靠效应。连接词窗口结构效应保持为 -1.14 ，t = -3.57 ，p 小于 0.001 ，接受者重音出现为 -0.85 ，t = -3.40 ，p = 0.001 。曲线上跨重音的结构差异在 -1,300 ms 到 0 ms 显著，中性下为 -854 ms 到 0 ms 。接受者与中性差异为 -446 ms 到 0 ms ，主题与中性仅 -39 ms 到 0 ms 。分结构看双宾中接受者差异为 -643 ms 到 0 ms 而主题无差异，介词中主题差异为 -249 ms 到 0 ms 而接受者无差异，呈现线索诊断性。

#### 模型注意力滞后且幅度更小

模型停顿窗口无主效应，仅结构与主题交互 p = 0.025 。连接词窗口结构效应为 -0.17 ，p = 0.005 ，主题为 0.05 ，p = 0.029 ，接受者为 -0.04 ，p = 0.096 边缘。曲线上跨重音结构差异仅 -13 ms 到 0 ms ，中性下为 -194 ms 到 0 ms ，比人类中性下 -854 ms 晚约 650 ms 。分结构诊断性模式相同但推迟：双宾接受者差异为 -220 ms 到 0 ms ，介词主题差异为 -181 ms 到 0 ms 。输出相似伴随时间分离，支持部署分离预测，而非共享部署。

### 单模型单结构与代理指标限制了结论的外推边界

结论成立依赖单一多模态大模型与单一普通话与格预测任务。所见部分输出一致、更高排除率与滞后注意效应可能来自该架构、训练数据、提示模板或特定结构重音操作。未检验其他语音视觉模型、尺寸、提示与解码设置，不能外推到多模态大模型整体。人类样本限于普通话大学生与一个构式，跨语言、跨构式与跨韵律体系的诊断性模式是否成立仍待检验。

#### 任务约束与时间部署的差异

人模任务高度匹配但感知环境并不相同。人类在实验界面听自然语音看 1,024 × 768 显示，模型经处理器接收音频与 1,008 × 756 拼图并附加任务提示，显示按切分调整间距。这些适配为可控比较所必需，但两者并未暴露于同一物理环境。模型侧在线指标为音频查询对图像键的跨模态注意操作定义，并非人类注视的直接等价物，层与头的聚合、区域映射与归一化均含设计选择，未做因果干预或梯度加权归因，不能定位负责效应的层头。

#### 输出权重的分歧与诊断性用法

输出层面部分一致但权重不同。模型结构效应约为人类 3 倍，在重音与默认焦点指向同一成分的条件下出现与人类相反的移动。时间上人类结构效应在中性条件下从 -854 ms 起可靠，模型从 -194 ms 起可靠，相差约 650 ms 。在双宾结构内人类接受者重音从 -643 ms 起区别于中性，模型从 -220 ms 起区别于中性。两者都呈现重音在缺乏默认焦点的成分上作用更明显的诊断性组合，但模型整体滞后。这种滞后反映测量到的注意分配轮廓差异，不直接等同于机制不同的断言。

#### 复现核对与后续比较方向

复现核对需区分三件事。分析脚本、提示代码、注意提取流程、模型输出、匿名化人类数据、刺激元数据、音频与显示元数据在论文数据可用性声明中列出仓库地址，本次收到清单将其标为第三方可达，状态为 200 ，不等同于作者资源已公开或可直接运行。听觉刺激为北京男性发音人录制，填充与规范细节见附录。统计采用混合效应与可加模型实现，一阶自回归校正经比较确认更优，随机斜率经前向比较保留最复杂可收敛结构。

选型上输出相似不宜直接读作加工机制相同。本范式下应同时报告输出选择、在任务空间内的约束可靠度与过程敏感的时间曲线。模型在显示外生成较多，人类进入分析 4,015 条，模型进入分析 2,881 条，约束可靠度本身即是差异所在。若要在工程中借用该模型做语音指称预测，需预留重音在非默认位置才最有效的诊断性用法，并为结构偏置过大与画面外生成准备约束解码或人工核查。后续可扩展多模型多语言比较，辅以分层与干预性归因，检验滞后是架构固有还是提示与切分所致。

#### 刺激筛选与统计建模的补充

刺激经过多轮筛选与规范。50 个初始项目改写自两组已有材料，经音节匹配、实体唯一、可图像化与视觉可区分筛选为 42 个。完形规范由 159 名普通话者完成，得到 6,678 个有效数据点，为每条件选定最高概率目标并避开重复实体与难成图实体。录音由一名北京男性发音人在隔音室以 44.1 kHz 完成，重音词在脚本中标红引导对比重读，中性条件保持平稳。句首偏移至连接词前静音统一为 700 ms ，连接词而不是时长统一为 600 ms 并保留基频轮廓，自然度规范最终保留 36 个项目，总体均值 3.22 。

统计上离线与在线采用不同模型但编码一致。实验 1 以替代主题为 1 、替代接受者为 0 ，结构和差编码为双宾 -0.5 与介词 0.5 ，重音以中性为参照，合并分析再以人类为参照加入被试类型，随机斜率经前向比较保留最复杂可收敛结构。实验 2 在暂停与连接词两窗内分别拟合线性混合模型，人类以被试与项目为分组，模型以 28 层为分组而非认知等价物。时间曲线再用可加混合模型拟合，以逐点置信区间不含零的区间为可靠差异窗，整体截距不显著而局部显著解释为晚期才分叉的预测效应。
