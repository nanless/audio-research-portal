## 📌 核心摘要

**问题与瓶颈：** 可听性在文中被形式化为对口语话语的全局优化，目标是传递最多信息的同时最小化听者认知负荷，并将通用语音参数适配到智力障碍或言语障碍等脆弱人群，以促进数字包容。现有路线存在两处断裂，一是 Flesch 与 SMOG 等传统可读性公式各自带有方法偏置，难以单独度量文本形式难度，二是长期默认自动语音识别性能随源文本语言复杂度变化，把文本难度与声学可懂度混为一谈。该任务横跨自然语言处理、音频信号处理、认知科学与人机交互，输入涉及文本复杂度与退化语音，输出应为可解释的难度度量与适配策略，但自 20 世纪 50 年代以来的学科割裂使其缺乏统一定义与测量。

**核心思路与方法架构：** 与最接近的单公式评估与自然语音混杂对比相比，本文增量是用等权归一融合 6 个经典公式的全局可读性指数统一文本难度，并用合成语音控制管线把文本难度与发音变异彻底分离，保留基于大模型的简化与语义校验。沿一条样本看，输入一段正式文本先被映射为 0 到 10 的全局可读性指数得分，原文未说明分词实现与各公式理论边界具体取值，再经大语言模型接口 Gemini 1.5 Flash API 做儿童导向单次改写，以替代缓慢的渐进迭代，原摘要与简化摘要分别经句子嵌入模型 Sentence-BERT 编码为稠密向量并计算余弦相似度，以检验语义保持。同一文本经语音合成服务 Amazon Polly 合成为受控语音，叠加 0 dB 到 20 dB 的 babble 噪声与模拟房间脉冲混响后送入多种自动语音识别架构，以词错率 (Word Error Rate, WER, 越低越好 ↓) 度量转写准确度，并辅以预测词元熵与 zlib 压缩比检验计算负荷，所有预训练模型仅用于评估，原文未提及任何训练、微调或参数更新。

**关键实验与核心代价：** 在文本简化评估中，儿童导向改写在单次执行下将正式文本的全局可读性指数均值从 µ = 9.97 变为 µ = 4.30，原文描述为难度下降超过 50%，有效配对的摘要间余弦相似度均值为 µ = 0.82，σ = 0.07，高于随机对照配对的 µ = 0.17，σ = 0.16，表明结构简化同时保留核心语义。在 CLEAR 语料加 Amazon Polly 合成并经 babble 噪声与混响降质的受控条件下，端到端模型 Whisper Tiny 与 Medium 的语言复杂度与 WER 相关为 r = 0.03，p = 0.059，接近零相关，在 LibriSpeech 语料自然语音上验证为 r = -0.02，同样接近零，而预测词元熵 r = -0.01 与 zlib 压缩比 r = -0.08 也无变化，证实转写不受形式复杂度影响，与之对照的是人工标注难度与 WER 错误仍保持 r ≈ -0.28 的持续相关，揭示人机分歧。听感方面原文缺人工主观平均意见分听测，也未使用 UTMOS 与 DNSMOS 等神经代理指标，仅以 WER 作可懂度代理，主客观一致性无法判断，主要代价是结论暂限于合成控制语音与通用文本，未覆盖脆弱人群真实聆听与认知负荷测量，且推理与部署成本未量化。

**适用边界与深读导览：** 上述解耦结论成立前提是受控合成语音加人工降质与现代端到端架构，不适用于真实脆弱人群的注意、记忆与听觉努力波动，也不覆盖自然病理语音、真实房间与多语言部署失效场景，等权融合的权重合理性仍待验证。欲深究归一融合公式的变量定义与取值边界可查阅方法概述和架构，欲核对简化与解耦的完整数值对照可查阅实验结果，欲了解系统综述与人类行为范式规划可查阅未来路线与局限章节。

## 🧭 深度解读

### 可听性为何难以统一定义并适配脆弱人群

可听性概念最早出现于 20 世纪 50 年代的无线电与电信领域，当时研究者关注如何让广播语音信号被听众尽可能清晰地感知。本文把它重新形式化为口语话语的全局优化问题，目标同时包含传递尽可能多的信息与降低听众认知负荷，用日常语言表述就是把话说得既简单又有效。该概念天然横跨自然语言处理、音频信号处理、认知科学与人机交互，博士研究希望建立统一理论模型以刻画这些维度之间的相互作用，并最终把通用语音参数适配到脆弱人群的实际需求。

在输入输出层面，该工作把研究对象界定为从文本难度到语音实现再到听众理解的完整链条，输入包括语言层面的句法与词汇复杂度以及声学层面的发音、噪声与混响条件，输出是经过适配后更易被特定人群接收的话语形式。评价不仅看机器转写是否正确，还要看信息保留、注意力维持与听觉付出等认知侧效果。为此作者提出 3 个相互关联的研究问题，分别对应如何形式化定义可听性、如何优化各影响维度并处理跨学科关联、如何把通用模型参数动态适配到脆弱人群以实现数字无障碍部署。

已有主流路线存在两类具体瓶颈。在文本侧，传统可读性公式如 Flesch 与 SMOG 各自带有方法偏置，单一分数难以稳定反映真实难度。在语音侧，长期存在一种历史假设，认为自动语音识别性能与源文本语言复杂度相关，早期混合架构如 Kaldi 与基于联结时序分类的模型确实对文本复杂度敏感。更深层的困难是学科割裂，可听性的各个侧面自 20 世纪 50 年代起被分别讨论，却缺少现代跨学科的形式化共识，这使得不同社区的指标与结论难以直接比较。

脆弱人群的适配进一步放大了难度。作者明确指向智力障碍者与言语障碍者等群体，他们在话语处理上既存在人与人之间的稳定差异，也存在同一人在注意力波动与认知疲劳下的动态变化。第一年工作先把文本与语音变量分离，控制发音差异以观察纯文本难度的影响，后两年则计划转向系统性、多模态与以人为中心的建模，把认知维度直接叠加到已有自动框架之上，并在真实场景中检验信息保持与听觉付出。

### 博士框架总览与第一年已完成的分离思路

博士总体路线围绕 3 个研究问题展开。定义层面通过系统文献综述综合现有研究，建立基于共识的可听性定义，作为后续研究的标准化起点。优化层面分别处理可读性与可懂度等子维度，并关注它们之间的跨学科关系。应用层面研究个体间差异与个体内动态变化，考察不同用户画像如何调节话语处理，以及注意力与疲劳如何随时间变化，最终转化为可操作的数字无障碍方案。该路线依托法国图卢兹大学与澳大利亚昆士兰科技大学的联合培养安排，借助国际流动获得基础设施与实地测试机会。

与最近既有做法相比，第一年工作的实质增量体现在两处。文本侧保留 6 个经典可读性公式，但不再单独使用其中之一，而是通过标准化融合为单一全局可读性指数，以削弱单个指标的偏置。语音侧保留以 WER 作为可懂度的自动代理指标，但替换了自然录音中文本难度与发音变异相互混杂的评估方式，改用合成语音固定发音方式，再人工叠加噪声与混响，从而在受控条件下检验架构鲁棒性。同时保留新老架构对照，用现代端到端模型对比传统混合与统计模型。

由于原文未披露采样率、帧长、步长、通道数、特征维度与码率等信号规格，这里只能追踪逻辑层面的端到端数据流。文本支路为原始形式文本先计算全局可读性指数，再经 Gemini 1.5 Flash 改写为简化版本，最后对原文与简化文的摘要做 Sentence-BERT 稠密嵌入余弦相似度校验。语音支路为取自 CLEAR 语料的文本经 Amazon Polly 合成为固定发音音频，再叠加 0 dB 到 20 dB 巴布尔噪声与模拟房间脉冲混响，接着送入 5 种识别架构解码，最后统计 WER 与文本复杂度、人工难度以及预测不确定性之间的相关性。两条支路在可听性解释层面汇合。

该阶段没有模型训练过程，所有识别模型与语言模型均处于冻结推理状态，实际操作是提示改写、受控合成与离线解码。文本简化比较渐进迭代与儿童导向改写两种策略，语音侧比较 Transformer 序列到序列、Transformer 与联结时序分类结合、隐马尔可夫与深度神经网络结合、隐马尔可夫与高斯混合结合等不同技术路线。推理侧的采样步数、前瞻窗口、缓存机制、延迟、TTFA 与 RTF 等部署细节原文均未披露，因此尚无法从工程角度评估流式可行性。

### 全局可读性指数如何融合偏置并验证简化保义

全局可读性指数 GRI 的动机是解决传统公式各自偏置的问题。作者把 6 个经典公式的分数分别按各自理论最小值与最大值做标准化，再取平均并乘以 10 ，得到 0 到 10 的单一分数，分数越高表示文本越复杂。这种等权平均是一种起点性选择，作者在后续规划中明确提出要与计算文本分析专家合作，在数学上优化并重新校准每个组成公式的权重系数，以增强语言学与统计严谨性。

基于该指数的自动简化流程由 Gemini 1.5 Flash API 驱动，比较了渐进迭代改写与儿童导向改写两种策略。报告的典型效果是形式文本基线均值 9.97 经儿童导向模型一次执行降至均值 4.30 ，降幅超过 50% 。这一数字说明结构简化在指数层面非常高效，但它本身只反映表面复杂度下降，并不直接证明信息无损或更易被脆弱人群理解，需要独立的保义校验。

保义校验通过摘要语义接近度完成。作者分别对原始文本与简化文本生成摘要，再用 Sentence-BERT 稠密嵌入计算余弦相似度，有效配对的均值为 0.82 ，标准差为 0.07 ，而随机对照配对的均值仅为 0.17 ，标准差为 0.16 。两者差距表明简化过程在很大程度上保留了核心语义概念，支持结构简化与语义保留可以兼得的判断。但该校验仍是自动语义相似度，并未测量人类阅读后的理解率与记忆保持。

该模块的边界同样清晰。权重等权是否最优尚未验证，6 个公式的具体名单与理论边界取值原文未完整展开，样本量与文本领域分布也未披露。作者把公开发布开源代码仓库作为未来目标之一，希望为语音与语言社区提供偏置更小的可读性评估工具，但当前阶段尚无可验证的公开链接，复现仍需依据论文文字自行实现标准化与融合步骤。

### 声学控制流程如何把发音差异从文本难度中剥离

第二条支路的核心目标是把形式文本难度与人类发音变异分开。自然录音中不同说话人的口音、语速与清晰度会干扰判断，难以确定识别错误究竟来自文本太难还是说得不清楚。作者因此采用 CLEAR 语料的文本内容配合 Amazon Polly 语音合成，使同一文本获得稳定的声学实现，再在生成音频上施加声学退化，包括加性巴布尔噪声 0 dB 到 20 dB 与模拟房间脉冲混响，以在接近真实环境约束下评估架构鲁棒性。

评估覆盖多种识别架构，包括 Whisper Tiny 与 Whisper Medium 两种 Transformer 序列到序列模型，Wav2Vec2 Base 的 Transformer 与联结时序分类路线，Vosk 的隐马尔可夫与深度神经网络路线，以及 PocketSphinx 的隐马尔可夫与高斯混合路线。在本文语境中，可懂度被定义为自动识别模型的客观性能，以 WER 作为转写准确性的代理指标，WER 越低表示可懂度越高。同时作者用预测词元熵与 zlib 压缩比作为模型计算负荷的侧面观察，检验复杂文本是否带来更高的解码不确定性。

为避免合成语音带来的特殊性，作者进一步用 LibriSpeech 自然语音验证趋势，并引入人工标注难度 BT 易读度作为对照。GRI 代表自动计算的形式复杂度，BT 易读度代表人类判断的主观容易程度，两者与 WER 的相关模式不同，正是揭示人机分歧的关键设计。如果机器错误只跟随 GRI ，则说明形式句法主导，如果机器错误跟随人类难度，则说明存在公式未捕捉的潜在感知因素。

该流程仍有大量执行细节未披露。合成所用音色、语速、采样率与后处理参数未知，噪声与混响的具体混合比例、信噪比抽样方式与房间参数未知，各架构的解码超参、语言模型配置与文本归一化方式也未知。这些缺失意味着他人难以逐样本复现同一退化条件，只能复现高层思路，即先固定发音再加受控退化，最后做跨架构相关分析。

### 现代端到端模型为何对文本复杂度免疫却仍受人类难度影响

评测协议的公平性前提需要先交代清楚。文本复杂度侧以 GRI 0 到 10 为横轴，分数越高越复杂，识别侧以 WER 为纵轴，数值越低越好。人工侧以 BT 易读度为横轴，数值越大表示人类判断越容易。比较在同一合成加退化条件下跨架构解码完成，未说明因果流式与离线解码的区分，也未报告多次运行的方差与置信区间。LibriSpeech 自然语音作为第二验证源，用于检验合成条件下的结论是否延续到真实朗读。

综合正文数字可以得到三点判断。第一，现代端到端模型呈现结构解耦，Whisper 的 GRI 相关仅为 0.03 且显著性为 0.059 ，LibriSpeech 上为负 0.02 ，预测词元熵相关为负 0.01 ，zlib 压缩比相关为负 0.08 ，表明在非常复杂与非常简单的文本之间转写性能几乎没有变化，而较老的混合与联结时序分类模型仍保留一定敏感性。第二，人机分歧持续存在，识别错误与人工标注难度相关约为负 0.28 ，当代模型对形式句法免疫，却仍对人类感到困难的潜在因素敏感。第三，代价是证据仍停留在自动指标层面，语义保留只用自动余弦相似度衡量，缺少听众数与置信区间明确的人工听测，也缺少 MOS 类主观评分，因此尚不能直接推及脆弱人群的真实信息保持效果。

### 结论边界、复现前提与后两年人体验证路线

结论成立依赖若干明确假设。首先是以 WER 作为可懂度的代理，默认转写错误等价于人类听不清，但机器转写与人类理解并不完全一致。其次是以 GRI 作为形式复杂度的代理，默认等权融合足以代表句法与词汇难度，而权重尚未优化。再次是合成控制假设，默认固定合成音可以完全中和发音变异，且巴布尔噪声加混响足以代表真实环境约束，但真实场景中的口音、语速、重叠语音与设备差异远比该退化丰富。

未验证的部署条件集中在以人为中心的一侧。第一年工作尚未纳入脆弱人群被试，没有测量自然场景中的信息保持、注意力跨度与客观听觉付出，也没有刻画个体间差异与个体内动态变化，例如不同障碍画像如何调节话语处理，以及注意力波动与认知疲劳如何随时间累积。在缺乏生态验证之前，文本简化带来的 GRI 下降与语义相似度保持，还不能等同于脆弱人群可理解性的提升，识别侧的解耦结论也不能直接指导助听或无障碍播报选型。

复现核对需要区分三件事。代码是否开源、权重是否提供下载、系统是否可直接运行，在本次材料中均无可验证的作者资源链接，不得视为已公开。后续规划包括完成系统文献综述并投稿同行评议期刊，数学上精炼 GRI 并发布公开代码仓库，以及与计算文本分析专家合作保证严谨性。国际联合培养提供的流动与实地测试机会，是把理论模型转化为数字无障碍方案的重要前提，但具体行为实验范式、被试规模与伦理安排尚未公布。

对刚进入该领域的研究生而言，工程选型建议是分层看待证据。需要大幅降低形式难度时，儿童导向改写在自动指数上效率很高，但必须补做人类理解测试以确认保义。需要选择识别架构时，端到端模型在文本复杂度鲁棒性上占优，但不能指望简化文本来降低 WER ，仍需关注人类主观难度指向的潜在感知因素。作者声明在本文写作中未使用生成式人工智能辅助技术，这一声明本身也是博士阶段工作可信度核查的一部分。
